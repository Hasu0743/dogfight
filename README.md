# dogfight — 航空格闘戦シミュレーター

ブラウザで動く近接格闘戦（ドッグファイト）シミュレーターです。相手の射線（ガンコーン）に入り続けると撃墜されます。

## 遊び方

- **[index2.html](index2.html)** … 最新版。AI対戦・オンライン対戦（ランダムマッチ／フレンド戦）に対応。ジェット9機種＋レシプロ4機種。
- **index.html** … 初期版（F-16 vs Su-27）。
- **index3.html** … 実験版（失速モーメントの試作）。

操作: `W/S` ピッチ ・ `A/D` ロール ・ `Q/E` ヨー ・ `R/F` スロットル ・ `Space` エアブレーキ ・ `Shift` 敵機を見る

## オンライン対戦サーバー

`server.js` はゲームロジックを持たない軽量な中継サーバー（Node.js + `ws`）です。各クライアントが自機の物理演算をローカルで行い、状態を中継サーバー経由で相手に送ります。

```bash
npm install
node server.js   # ws://<このPCのIP>:8080 で待受
```

## 注意

- 機体パラメータは公開情報に基づく概算値で、実機の正確な性能を保証するものではありません。
- 中継サーバーはクライアントの自己申告を信頼する設計（カジュアル対戦向け）です。
